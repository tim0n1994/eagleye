# 情报工作台重构

日期：2026-11-09。

## 页面与阅读流程

顶层入口为发现 `/discover`、专题 `/topics`、趋势 `/trends`、关注 `/watchlist`。

- 发现：按最近收录或来源数排列材料，原文链接相同的条目合并成一张卡；显示来源、AI/来源摘要、专题、实体、可展开的证据。
- 专题：使用稳定 taxonomy 与旧 topics 的 slug。相同 slug 的分类合并，关联证据取两套 assignment 的并集，并按 item 去重。专题详情显示时间分布、相关实体和原文；支持关注。
- 趋势：相邻等长窗口的条目提及量、来源数、变化量和支撑材料。不存在上期数据时不显示无穷增长率。它衡量已收录材料，不是营收、份额或行业整体规模。
- 关注：沿用按用户隔离的 watchlist，新增 topic 订阅，与已有 entity/type 订阅兼容；提供日期回看、取消关注和证据列表。
- 系统状态 `/system-status`：当前读取窗口内的摘要、专题、实体加工覆盖；不再作为行业指标。来源未出现不能据此判断健康。

`/kg3d` 显示专题，`/intelligence` 显示趋势，`/industry-metrics` 显示系统状态。旧链接仍可用；`/api/kg3d` 返回 410 并告知替代入口。3D 页面、Three.js、3d-force-graph、加载器入口及 CSS 已移除。知识抽取与概念图数据继续保留，其他页面既有二维图不受影响。

## 性能与实现

- 新页面按需 import `pages/radar.js`，不请求图谱、不加载图形库。
- 单个 `/api/radar` 查询提供页面数据。认证复用主服务；关注信息不进入共享缓存，HTTP 响应 `private, no-store`。
- `radar.js` 管理单个只读 worker；SQLite 查询、聚合、URL 归并均在 worker 内执行。主 HTTP 线程只做路由、订阅读取和结果发送。
- `radar-worker.js` 用只读连接及读事务获取一致视图。缓存 5 分钟，最多 3 个日期/周期组合。相同并发请求共享 Promise；最多 12 个未完成请求，20 秒超时后终止并重建 worker。
- 使用已有 `idx_items_digest_date`，避免优化器选择 duplicate_of 索引后全量排序。两期各取最多 6,000 条，关联数据按 400 个 item ID 批量读取。
- 每页 30 张卡或 30 个趋势对象，证据最多展开 12 条；超出会提示。前端使用普通 HTML/CSS 时间条，折叠证据与 content-visibility；路由切换会取消请求。
- 没有新增依赖、数据库迁移、在线 LLM 调用或后台全量重建。

## 数据契约与边界

- date 是截至的收录日期，days 只支持 1、7、30；默认日期按 Asia/Shanghai 计算。窗口首尾都包含，上期与本期长度相同且互不重叠。
- `duplicate_of IS NULL` 是共同入口口径。实体按同一 item 去重，专题 assignment 合并后去重；发布时间另行显示，不用收录日期冒充发布时间。
- 达到任一期读取上限时，meta.partial=true，页面显式提示部分覆盖，变化量与增长率返回 null。新专题、稀疏关注对象可能因全局窗口上限而遗漏；缩短时间范围可减轻影响。
- 两期来源数与证据一起展示；补采、停采、新增来源以及尚未结束的当天均会影响比较。
- 事件归并只认规范化后的同一原文 URL，去除已知追踪参数但保留业务参数；不同链接不会因标题相似自动合并。稳定哈希 ID 来自该 URL，代表材料组，不宣称已完成跨链接事件识别。
- 当前是可重建的内存读取快照，不是永久冻结的日报快照；晚到材料与重新加工会改变历史查询结果。原始材料及现有日报存储不变。
- 实体及专题准确性取决于现有抽取和 assignment，本轮没有改写模型或历史知识数据。

## 验证与发布

在当前真实数据库上做了只读查询及六种页面的基础 DOM 渲染（发现、专题列表、专题详情、趋势、关注、系统状态），并检查了语法、定向 ESLint 和 diff 格式。没有构造模拟语料、额外测试用例、benchmark 或专用测试环境；关注写入和真实使用效果留给用户验收。

一次基本读取中，修正索引前首次读取约 9.5 秒，修正后约 0.7 秒；缓存下专题约 14 毫秒。该记录仅用于确认查询计划修复生效，不代表生产 SLA。

工作区与在线 release 目录不同。用户已要求合并主线并上线；发布包含新增 radar 服务/页面/CSS 及入口变更。新 API 和前端应在同一版本发布；没有本轮数据库迁移。
