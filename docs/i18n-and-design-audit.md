# 国际化与工作台视觉整理

日期：2026-11-11。范围：Eagleye 浏览器界面、共享渲染与相关 API 返回字段。

## 已处理的问题

- 主词典原有键已对齐，但页面仍有硬编码提示。本轮补齐首页、导航、命令面板、来源质量、图谱、设置、阅读与研究页面的双语文案。
- `pickZh()` 原先仅接受字符串，中文要点数组被忽略；现在支持非空数组，并保留原文回退。
- 旧列表和首页文本导出优先显示中文标题；改为尊重当前语言。
- 日期与数字采用统一 locale；无效日期显示未知。日历日期不因 UTC 解析产生跨天。
- 导航、按钮提示、无障碍标签、页面描述、登录入口与命令面板跟随语言更新。
- 命令面板补齐中文、键盘选择、关闭和焦点返回；移动端导航使用可展开菜单。
- 语言切换后恢复可识别的表单输入、展开区和滚动位置。
- 首页搜索原先匹配 `.info-card`，实际渲染 `.mini-card`；已修正筛选、标题匹配与数量显示。
- API 补充已有的来源中文标签、论文和信号摘要双语字段，以及 For You 的中文标题，供前端选择，不引入数据迁移或批量翻译。
- 注册与重发请求携带当前语言，验证码邮件提供对应语言的 HTML 和纯文本版本；未实际发送邮件。

## 视觉实现

保留 Eagleye 橙色与现有品牌，建立石墨/暖白双主题。统一颜色变量、中文字体回退、阅读层级、表单、焦点、触控区域和错误状态。首页由醒目的品牌装饰转为当日阅读标题、简报与来源阅读队列。

设计规则详见根目录 `design.md`；这份规范以每月 20 美元产品的前端完成度为目标，未新增支付、计费或订阅承诺。

## 内容边界

- 第三方原文、历史 LLM 简报、来源名称与后端诊断不是 UI 翻译键。无已存储译文时保留原文，不能据此宣称所有历史内容都有双语版本。
- 操作日志和模型输出保留诊断内容；外围标签和状态提供双语。
- 本轮不触发抓取、LLM 翻译、邮件发送、订阅收费或生产部署。
- 用户已有的 `.env.example` 修改保持原样。
