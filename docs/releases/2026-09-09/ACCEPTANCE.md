# Eagleye 1.1 本地发布候选验收

日期：2026-09-09。范围：现有 Eagleye 工作树及隔离数据库；没有公开部署、发送邮件或替换原数据库。

## 产品结果

五个本地 Anthropic Messages 路由进入同一个进程级端点池。全局并发默认 5、每路 1；请求有排队上限、总时限、最多两条不同路由尝试、取消、熔断与热更新。模型名称不再决定协议。摘要、翻译、研究保存实际响应模型、端点及 trace；探活与业务质量明确区分。

全局数据操作仅管理员可用，并验证 HTTP 方法及批量上限。危险全量重富集入口停用。取消贯穿任务、请求与结果写入；重启保留完成阶段，明确标记中断阶段。调度不把不确定的入队收据自动重放。32 个迁移可在空库和已有库执行；单个迁移及其标记在同一事务中。

内容真实性是本轮真实验收发现并修复的额外门槛。没有正文的内容生成来源标题卡片，明确细节未核验，不请求摘要模型。条目研究直接引用存储的原始材料，逐字校验模型引文，将分析与事实材料分开；短描述不再强制扩写长报告。

## 真实端点与性能

`endpoint-probe.json` 记录五路真实 HTTP 样本。lane-2 在 384 token 时截断，2048 token 复测成功，记录于 `endpoint-2-token-probe.json`。lane-5 的实际返回模型带 `self-dploy/` 前缀，业务记录保留该值。

| 同一组 10 条合成事实 | 单 lane-5，并发 1 | 五路池，并发 5 |
|---|---:|---:|
| 完成且满足结构/事实样本检查 | 10/10 | 10/10 |
| 总墙钟时间 | 118.287 秒 | 16.162 秒 |
| 此次样本吞吐比 | 1 | 7.319 |

以上来自 `throughput-benchmark-repeat.json`，是一次有界对照，不代表长期收益、所有业务或五台独立算力。共享网关、路由速度差异及排队都会影响结果。第一次对照单路 9/10 成功，因此 `throughput-benchmark.json` 保留为失败记录，其时间比不作为有效加速结论。独立审查发现并修复了单条适用路由也被减半超时的问题。

可复现 CLI：`scripts/acceptance/benchmark-llm-pool.js`。要求显式私密配置路径和新报告路径，拒绝覆盖旧报告；不读业务数据库，不保存密钥。该 CLI 提供当前重复实验入口，上述两个历史 JSON 由同一批次策略的临时验收脚本生成，未伪称使用后来新增的 CLI。

真实网关对一次合成错误 key 的探活也返回成功。因此“探活成功”只能证明协议响应，不能证明网关检查了 key。现场确认网关仅监听 `127.0.0.1:56185`；未修改网关鉴权策略。本应用的管理员权限与密钥打码独立验证通过。

## 数据闭环与纠正记录

- Hacker News：最多 20 个候选，新增当天 3 条、17 条因日期等规则跳过，未隐含富集。第一次 TLS 失败记录为失败；修正 HTTP(S) Agent 对环境代理的支持后重试成功。不能仅由这次重试断言代理是唯一故障原因。
- GitHub：1 次源请求、最多入库 5 条，实际新增 5 条且都带真实仓库描述。5/5 摘要和评分完成，实际摘要分别来自 lane-4 与 lane-5；分类及研究也使用了其他路由。见 `live-github-result.json`、`live-github-output.json`。
- KG：Hacker News 与 GitHub 受控提取完成，8 条新条目都有特征；提取没有使用模型生成的摘要。哈希向量仍不是语义模型，本轮没有声称修复全部语义聚类覆盖。
- 标题无正文的 3 条 HN 摘要最初出现不支持的扩写，已在本轮 RC 按精确 ID/trace/时间戳纠正，撤销其 15 条 v1 标签关联、4 条主题关联、23 条图边并重算 3 条评分。完整前值、事务条件和执行结果保存在 `title-only-repair-*`，原始资料及有效 KG v2 数据保留。
- 初始研究报告混淆了发布者元数据、AI 派生内容与推理，并加入没有依据的定量判断，已在 RC 标记 superseded。React/Next.js 标签确实存在于原始仓库 topics，不能说这些名称凭空生成，但它们也不等同代码核验。修后真实报告为 844 字符，只有真实材料、逐字引文、待核验假设与问题，实际模型为 GLM。见 `live-research-corrected.json`；原失败报告留作回归证据。
- 20260907 单条新 GitHub 内容的真实简报任务 completed，实际 lane-3 / gpt-5.6-luna，引用的 item ID 与输入一致；输出明确生成质量与生产可用性未知。见 `live-digest-result.json`。该样本验证简报落库与模型归属，不代表大批量简报质量。

## 可靠性与权限

`http-role-matrix.json` 的 10 个真实 HTTP 角色/方法/参数场景通过。真实翻译任务在模型槽位 active=1 时取消，最终 cancelled、active=0、queued=0；见 `live-cancel-*`。真实 KG 子进程关闭返回 stopped=1、errors=[]。

RC 进程收到 SIGTERM 后以 0 退出。重启后五路配置保留；专门构造的中断恢复 fixture 保留完成的 fetch 阶段，运行中 enrich 标失败，待执行 digest 标跳过。fixture 是明确的恢复测试数据，不冒充一次实际完整流水线运行。见 `restart-recovery.json`。
